# 🧠 KONSEP FUNDAMENTAL KOMPUTASI & PEMROGRAMAN

### A. Konsep Inti
1. **Bagaimana Komputer Bekerja?**
   - **CPU (Central Processing Unit):** Otak yang mengeksekusi instruksi aritmatika dan logika (ALU).
   - **RAM (Memory):** Tempat penyimpanan data sementara berkecepatan sangat tinggi. Data hilang saat komputer mati (volatile).
   - **Storage (SSD/HDD):** Penyimpanan permanen untuk file, script, dan dataset.
   - **OS (Operating System):** Jembatan penghubung antara hardware dan software (Python runtime).

2. **Compiler vs Interpreter:**
   - **Compiler (C++, Rust):** Menerjemahkan seluruh kode menjadi bahasa mesin (binary) sekaligus sebelum program dijalankan. Sangat cepat, tapi kaku.
   - **Interpreter (Python):** Menerjemahkan kode baris per baris saat runtime. Sangat fleksibel, cepat diuji coba, menjadikannya standar utama di Data Science dan AI.

3. **Algoritma, Pseudocode & Flowchart:**
   - **Algoritma:** Urutan langkah terstruktur untuk memecahkan masalah.
   - **Pseudocode:** Penulisan logika algoritma menggunakan bahasa manusia terstruktur tanpa aturan sintaks ketat.
   - **Flowchart:** Representasi grafis alur program (Oval: Start/End, Persegi: Proses, Belah Ketupat: Keputusan/Kondisi, Jajar Genjang: Input/Output).

### Hubungan dengan Data Science & AI:
Model AI sebesar apapun pada akhirnya bermuara pada alokasi memori (RAM/VRAM) dan operasi matematika matriks di CPU/GPU. Memahami konsumsi memori sejak dini mencegah kode Anda crash (*Out Of Memory*) saat memproses dataset berukuran gigabyte.

---

### E. Common Mistakes Pemula
1. Langsung mengetik kode tanpa merancang alur logika dan flowchart terlebih dahulu.
2. Tidak memahami batasan RAM saat memuat file data berukuran besar.
3. Mengabaikan terminal / CLI dan hanya mengandalkan klik mouse.

---

### F. Best Practices
- Biasakan membuat diagram alir (Flowchart) atau pseudocode sebelum mulai coding project apapun.
- Biasakan navigasi terminal: `cd`, `ls` / `dir`, `pwd`, `mkdir`.
