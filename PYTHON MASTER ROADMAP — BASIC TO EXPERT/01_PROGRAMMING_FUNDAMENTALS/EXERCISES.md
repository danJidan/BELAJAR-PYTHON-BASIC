# 📝 EXERCISES: PROGRAMMING FUNDAMENTALS

### Level Easy
1. Buat algoritma langkah demi langkah untuk menentukan apakah sebuah bilangan adalah ganjil atau genap.
2. Tuliskan pseudocode untuk menghitung nilai rata-rata dari 5 angka ujian.

### Level Medium
1. Gambarkan diagram flowchart untuk proses autentikasi login (Maksimal 3 kali percobaan salah sebelum akun terkunci).
2. Tuliskan pseudocode algoritma Linear Search untuk mencari angka di dalam sebuah list angka.

### Level Hard
1. Rancang algoritma untuk menyaring (filter) transaksi bank yang bernilai di atas Rp 10.000.000 atau terjadi pada jam 00:00 - 04:00 (deteksi anomali fraud sederhana).
