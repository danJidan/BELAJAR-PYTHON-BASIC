# 🏆 39_CAPSTONE_PROJECTS: SPESIFIKASI PROJEK AKHIR

Setiap projek akhir wajib memiliki standar industri:
1. `README.md` berstandar internasional (Problem, Solution, Architecture Diagram, Setup Instructions, Results & Business Impact).
2. Kode teruji dengan Unit Testing (`pytest`) coverage > 80%.
3. Docker containerization (`Dockerfile` & `docker-compose.yml`).
4. Pipeline CI/CD otomatis di GitHub Actions (Linting, Typing, Testing).
