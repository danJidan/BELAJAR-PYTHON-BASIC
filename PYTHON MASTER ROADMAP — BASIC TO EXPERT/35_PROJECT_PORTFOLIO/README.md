# 💼 35_PROJECT_PORTFOLIO: STRUKTUR PORTOFOLIO PROFESIONAL

Untuk membuktikan keahlian Anda ke recruiter dan tech lead, susun portofolio dalam 5 tingkatan bertahap:

---

## 📌 LEVEL 1: 5 PYTHON FOUNDATION PROJECTS
1. **Interactive Financial Expense Tracker (CLI + JSON):** CRUD data keuangan dengan validasi dan pelaporan ringkas.
2. **Automated File Organizer & Renamer:** Script otomasi merapikan folder Downloads berdasarkan ekstensi file dan tanggal pembuatan.
3. **Multi-Threaded Web Scraper:** Mengambil data harga komoditas / katalog produk dan menyimpannya ke file CSV/SQLite.
4. **Mini CLI Text RPG Game:** Implementasi penuh konsep OOP (Class Karakter, Senjata, Inventory, Polimorfisme Pertarungan).
5. **System Health & Network Monitor Daemon:** Logging penggunaan CPU, RAM, dan latency ping ke file CSV harian.

---

## 📌 LEVEL 2: 5 DATA ANALYSIS PROJECTS
1. **E-Commerce Customer Retention & Cohort Analysis:** Menghitung retention rate bulanan dan menganalisis kapan churn terbesar terjadi.
2. **RFM Customer Segmentation:** Menerapkan segmentasi Recency, Frequency, Monetary untuk rekomendasi promosi tertarget.
3. **Marketing Campaign A/B Testing Validation:** Analisis konversi statistik dengan uji Two-Sample T-Test dan Chi-Square.
4. **Supply Chain Delay Diagnostic Dashboard:** Mendiagnosis faktor penyebab keterlambatan logistik menggunakan Python & Plotly.
5. **HR Attrition & Salary Diagnostic:** Menganalisis faktor pemicu resignnya talenta kunci di perusahaan.

---

## 📌 LEVEL 3: 5 MACHINE LEARNING PROJECTS
1. **Real Estate Price Estimator (Advanced Regression):** Mengatasi missing data, outlier handling, log transformation, dan ensemble stacking.
2. **Telco Customer Churn Prediction:** Mengatasi imbalanced data dengan SMOTE / Class Weights dan interpretasi fitur dengan SHAP values.
3. **Credit Risk & Default Probability Scoring:** Memprediksi probabilitas gagal bayar kredit nasabah bank.
4. **E-Commerce Customer Segmentation (Unsupervised):** Mengelompokkan pelanggan menggunakan K-Means dan evaluasi Silhouette Score.
5. **Product Recommendation Engine:** Collaborative & Content-Based Filtering untuk rekomendasi katalog barang.

---

## 📌 LEVEL 4: 3 DEEP LEARNING & AI PROJECTS
1. **Automated Medical Chest X-Ray Classifier:** Transfer learning menggunakan ResNet50 / EfficientNet pada dataset gambar medis.
2. **Customer Support Ticket Auto-Categorization (NLP):** Fine-tuning model BERT / RoBERTa untuk klasifikasi sentimen dan topik komplain pelanggan.
3. **Intelligent Document OCR & Information Extractor:** Ekstraksi data KTP / Invoice otomatis menggunakan OpenCV dan Vision Transformer.

---

## 📌 LEVEL 5: 2 END-TO-END AI SYSTEMS (CAPSTONE PRODUCTION)
1. **Enterprise Knowledge Base RAG Assistant:**
   - Arsitektur RAG lengkap dengan Vector DB (Chroma/Qdrant).
   - Verifikasi sitasi sumber dokumen PDF.
   - FastAPI backend dengan streaming response dan token authentication.
   - Dockerized dan siap deploy.
2. **Real-time Credit Card Fraud Detection Microservice:**
   - Pipeline data streaming.
   - Model inference berkecepatan tinggi (< 20ms) via FastAPI.
   - Logging eksperimen model dengan MLflow.
   - Automated CI/CD test dengan GitHub Actions.
