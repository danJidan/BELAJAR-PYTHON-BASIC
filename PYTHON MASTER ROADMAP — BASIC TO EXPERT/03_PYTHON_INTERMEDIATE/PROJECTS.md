# 🚀 MINI PROJECT: EXPENSE & BUDGET MANAGER
**Tujuan:** Membangun aplikasi pelacak pengeluaran berbasis CLI yang membaca dan menulis data ke file JSON secara modular.
**Spesifikasi:**
1. Struktur file modular:
   - `storage.py`: Fungsi khusus membaca dan menulis file `data_transaksi.json`.
   - `analytics.py`: Fungsi analitik menghitung total pengeluaran per kategori menggunakan dictionary & comprehensions.
   - `main.py`: Menu interaktif CLI.
2. Validasi error input nominal (tidak boleh negatif atau karakter non-angka).
