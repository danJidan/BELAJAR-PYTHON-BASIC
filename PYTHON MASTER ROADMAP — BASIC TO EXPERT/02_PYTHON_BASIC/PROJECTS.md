# 🚀 MINI PROJECTS: PYTHON BASIC

## Project: Sistem Kasir CLI Interaktif
**Objektif:** Menggabungkan variabel, loop, fungsi, list/dict, dan percabangan dalam satu program kasir minimarket.
**Fitur Wajib:**
1. Menampilkan daftar barang dan harga.
2. User bisa memilih barang berulang kali dan menentukan kuantitas.
3. Menghitung total belanja.
4. Jika total belanja > Rp 100.000, berikan diskon 5%. Jika > Rp 500.000, berikan diskon 10%.
5. Cetak struk belanja rapi dengan tanggal dan jam transaksi.
