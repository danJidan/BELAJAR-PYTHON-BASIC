# 🏋️ EXERCISES: PYTHON BASIC

### 🟢 Easy
1. Buat fungsi `is_palindrome(kata: str) -> bool` yang mengecek apakah sebuah kata sama jika dibaca terbalik (misal: "katak" -> True, "python" -> False).
2. Buat program yang mencetak tabel perkalian 1 s/d 10 menggunakan nested `for loop`.

### 🟡 Medium
1. **FizzBuzz Klasik:** Cetak angka 1 sampai 50. Kelipatan 3 cetak "Fizz", kelipatan 5 cetak "Buzz", kelipatan 3 dan 5 cetak "FizzBuzz".
2. Buat fungsi `hitung_huruf_vokal(teks: str) -> dict` yang menghitung berapa jumlah huruf a, i, u, e, o di dalam sebuah teks.

### 🔴 Hard
1. Buat sistem validasi password dengan aturan: minimal 8 karakter, memiliki minimal 1 huruf besar, 1 huruf kecil, 1 angka, dan 1 simbol karakter khusus. Return `True` jika valid, dan list alasan jika tidak valid.

### 🏆 Challenge
1. Buat algoritma konversi angka integer ke format Romawi (misal: `1994` -> `"MCMXCIV"`).
