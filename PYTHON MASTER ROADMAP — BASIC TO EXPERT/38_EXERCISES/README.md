# 🏋️ 38_EXERCISES: 10-LEVEL PROGRESSIVE SYSTEM

- **Level 1 — Syntax:** Latihan sintaks murni (variabel, operator, manipulasi string).
- **Level 2 — Logic:** Latihan alur logika (If-else, loops, rekursi dasar).
- **Level 3 — Problem Solving:** Soal logika pemrograman (FizzBuzz, Palindrome, Anagram).
- **Level 4 — Data Manipulation:** Transformasi data mentah dengan List & Dict comprehensions.
- **Level 5 — Algorithm:** Algoritma sorting, pencarian biner, dan two-pointer approach.
- **Level 6 — Data Analysis:** Pembersihan dataset kotor dan visualisasi distribusi data.
- **Level 7 — Machine Learning:** Menulis algoritma Linear Regression & KNN dari nol dengan NumPy murni.
- **Level 8 — Real World Project:** Membangun aplikasi scraper dan analitik terstruktur.
- **Level 9 — System Design:** Merancang arsitektur model serving dengan antrian background worker.
- **Level 10 — Expert Challenge:** Mengoptimasi latensi inferensi LLM dan caching semantic vector.
