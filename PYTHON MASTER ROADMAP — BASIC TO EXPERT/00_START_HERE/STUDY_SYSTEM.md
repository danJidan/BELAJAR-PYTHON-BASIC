# ⏱️ STUDY SYSTEM: FRAMEWORK BELAJAR EFEKTIF

Agar tidak terjebak dalam "Tutorial Hell", gunakan aturan berikut setiap hari:

## 1. Aturan Distribusi Waktu Harian (Daily 30-40-20-10 Rule)
- **30% Konsep & Teori:** Membaca dokumentasi/konsep, memahami *kenapa* dan *bagaimana*.
- **40% Coding Praktik:** Menulis kode dari nol tanpa copy-paste, eksperimen mengubah input dan memecahkan error.
- **20% Exercises / Soal Tantangan:** Mengerjakan latihan tingkat Easy, Medium, hingga Hard.
- **10% Review & Dokumentasi:** Mencatat hal baru, merapikan git commit, dan update checklist mastery.

---

## 2. Tingkat Penguasaan Materi (Mastery Progress Tracker)
Setiap topik diukur melalui 7 level penguasaan:
1. `[ ] Not Started` : Belum dibuka.
2. `[ ] Learning`    : Sedang membaca konsep dan teori dasar.
3. `[ ] Practicing`  : Mengetik contoh kode dan melihat hasilnya.
4. `[ ] Can Apply`   : Mampu mengerjakan soal latihan tanpa melihat solusi.
5. `[ ] Can Explain` : Mampu menjelaskan cara kerja konsep kepada orang lain secara sederhana.
6. `[ ] Can Build`   : Berhasil mengintegrasikan konsep ke dalam proyek mandiri.
7. `[ ] Mastered`    : Mampu mendebug error kompleks dan menjelaskan trade-off teknologi tersebut.

---

