## ⚖️ SKILL MATRIX: APA YANG WAJIB VS APA YANG TIDAK PERLU BERLEBIHAN

### 🟢 WAJIB DIKUASAI SANGAT DALAM [MUST MASTER]:
1. **Core Python Logic:** Dictionary, List comprehensions, Functions, Scope, Exception handling.
2. **Object-Oriented Programming (OOP):** Class, inheritance, encapsulation, magic methods (`__init__`, `__str__`, `__repr__`).
3. **Data Wrangling:** Pandas (`groupby`, `merge`, `loc/iloc`, data cleaning, missing values imputation).
4. **SQL:** `SELECT`, `JOIN`, `GROUP BY`, `HAVING`, `WINDOW FUNCTIONS` (`ROW_NUMBER`, `RANK`), `CTE`.
5. **Applied Statistics:** Mean/Median/Mode, Variance, Normal Distribution, P-value, Hypothesis Testing, Confidence Intervals.
6. **ML Rigor:** Data leakage prevention, Train/Test split, Cross-validation, Precision vs Recall vs ROC-AUC, Hyperparameter tuning.
7. **Modern AI Stack:** PyTorch, Hugging Face, LangChain/LlamaIndex concepts, Vector Database (Chroma/FAISS/Qdrant), RAG architecture.
8. **API & Engineering:** FastAPI, Pydantic, Git branch workflow, Docker containerization.

### 🟡 LOW PRIORITY (Cukup Tahu Konsepnya, Jangan Terjebak Lama):
- Menghafal seluruh syntax regex yang rumit (gunakan cheatsheet atau tools online).
- Membuat GUI desktop klasik (Tkinter/PyQt) — dunia modern berorientasi Web & API.
- Menghafal rumus turunan analitik kalkulus multi-variabel rumit di luar intuisi gradien/backpropagation.
- Menghafal ratusan hyperparameter library secara manual (gunakan dokumentasi resmi).

### 🔴 OPTIONAL — ADVANCED (Pelajari Saat Sudah Level Industri/Production):
- Python C-Extensions & Cython.
- Metaclasses & custom byte-code manipulation.
- Distributed cluster computing multi-node (Ray/Spark) sebelum data berukuran Terabyte.
