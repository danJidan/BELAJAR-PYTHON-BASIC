## 🚀 Cara Menjalankan Website di Localhost

Aplikasi web ini sepenuhnya mandiri (*standalone*), ringan, dan tidak membutuhkan build bundler yang rumit. Anda dapat menjalankannya dengan salah satu dari cara berikut:

### Opsi 1: Menggunakan Python (Sangat Direkomendasikan)
Jalankan file `server.py` yang otomatis membuka browser Anda:
```bash
python server.py
```
atau dengan perintah HTTP server standar:
```bash
python -m http.server 3000
```
Buka browser dan akses alamat: `http://localhost:3000`

---

### Opsi 2: Menggunakan Node.js / NPM
```bash
npm start
```
atau
```bash
npx serve . -p 3000
```

## 📚 Struktur 12 Bab Kurikulum Modul:

1. **BAB I — PENGENALAN FLOWCHART:** Definisi formal, algoritma, fungsi, tujuan, kelebihan/limitasi, tabel komparasi holistik (Algoritma vs Pseudocode vs Flowchart vs Program), serta contoh kehidupan nyata & biometrik.
2. **BAB II — SIMBOL-SIMBOL FLOWCHART:** Katalog 18+ simbol ANSI/ISO lengkap dengan bentuk visual vektor SVG beresolusi tinggi, fungsi teknis, kapan dipakai, contoh teks, kesalahan umum, pembedahan pasangan simbol yang sering tertukar, dan variasi standar.
3. **BAB III — JENIS-JENIS FLOWCHART:** 5 jenis utama (*System, Program, Process/Swimlane, Document, Data Flowchart*), komparasi tegas Flowchart vs Data Flow Diagram (DFD), serta matriks panduan memilih diagram.
4. **BAB IV — ATURAN DAN PRINSIP PEMBUATAN FLOWCHART:** 13 kaidah baku teknis (arah alami, konvergensi, terminator, anti-crossing lines, defensive error handling), disertai perbandingan visual langsung **Contoh SALAH vs Contoh BENAR**.
5. **BAB V — LANGKAH MEMBUAT FLOWCHART DARI NOL:** Metodologi terpandu 11 langkah dari narasi mentah ke diagram final, dipandu studi kasus tuntas: *Sistem Tarif Parkir Mall Berbasis Jam* lengkap dengan dekomposisi I-P-O dan Uji Meja (*Trace Table*).
6. **BAB VI — STRUKTUR KONTROL DALAM FLOWCHART:** Tiga pilar logika komputasi (*Sequence, Selection If/If-Else/Elif, Iteration While/For*), lengkap dengan pseudocode dan implementasi kode Python sinkron.
7. **BAB VII — KUMPULAN 20 CONTOH FLOWCHART (DASAR s.d. LANJUTAN):**
   - *Dasar:* Hello World, Luas Persegi Panjang, Rata-rata 3 Nilai, Ganjil/Genap, Kelulusan KKM.
   - *Menengah:* Terbesar 2 Angka, Terbesar 3 Angka, Diskon Belanja Supermarket, Kasir Restoran (PPN 11%), Login Kredensial, Deret Angka 1-N.
   - *Lanjutan & Sistem:* Faktorial ($n!$), Jumlah Deret, Grade Nilai A-E, Simulasi Mesin ATM (Validasi PIN & Saldo), Peminjaman Buku Perpustakaan, Registrasi Akun & Validasi Password, Pengolahan Data Mahasiswa & IPK, Sistem Tiket Pengaduan Layanan Publik, Proses Bisnis Checkout E-Commerce.
8. **BAB VIII — TOOLS PEMBUATAN FLOWCHART:** Ulasan tools Web (*Draw.io, Lucidchart, Miro*), Desktop (*Visio, Dia, EdrawMax*), Office (*Word, Slides*), dan Text-to-Diagram (*Mermaid.js*), dilengkapi langkah praktis.
9. **BAB IX — KESALAHAN UMUM DAN DEBUGGING FLOWCHART:** 10 kesalahan fatal (*shape mismatch, infinite loop, undefined variable, dead-end path, dll*) beserta cara deteksi dan solusinya.
10. **BAB X — LATIHAN DAN EVALUASI INTERAKTIF:**
    - 15 Soal Pilihan Ganda (dengan koreksi instan, skor otomatis, dan pembahasan mendalam)
    - 10 Soal Benar / Salah
    - 10 Latihan Identifikasi Simbol Visual
    - Latihan Menyusun Urutan Algoritma
    - 5 Tantangan Debugging Logika
    - 3 Proyek Mini
11. **BAB XI — PROYEK AKHIR TINGKAT ENTERPRISE:**
    - Proyek 1: *Sistem Penilaian Mahasiswa & Kelulusan Akademik*
    - Proyek 2: *Sistem Transaksi Point-of-Sale (POS) Kasir Toko Modern*
    - Proyek 3: *Sistem Registrasi & Layanan Pengaduan Fasilitas Digital*
    - Masing-masing dilengkapi Latar Belakang, I/O, Aturan Bisnis, Algoritma, Flowchart, Pseudocode, Test Cases, dan Rubrik Penilaian.
12. **BAB XII — RANGKUMAN, GLOSARIUM & DAFTAR PUSTAKA:** Rangkuman materi, Glosarium istilah A-Z, Checklist QA Mutu Diagram, dan Daftar Pustaka resmi terverifikasi (Dicoding, Sekawan Media, ITB Tuban, ISO 5807:1985, Donald Knuth).

## ⚡ Fitur Interaktif Unggulan

* **Flowchart Sandbox (Live Playground):** Editor berbasis teks bertenaga Mermaid.js dengan rendering real-time, template preset siap pakai, zoom in/out, dan salin kode.
* **Interactive Quiz Engine:** Mengerjakan soal latihan langsung di web dengan tombol cek jawaban dan skor otomatis.
* **Dual Theme (Dark / Light Mode):** Tampilan gelap modern (*deep slate glassmorphism*) dan terang yang nyaman di mata dengan penyimpanan preferensi otomatis.
* **Pencarian Cepat (Live Search):** Filter materi bab secara instan.
* **Ekspor Cetak / Print to PDF:** Tombol cetak khusus dengan CSS print yang memformat dokumen menjadi modul rapi tanpa sidebar.
